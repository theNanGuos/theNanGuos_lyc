# WU-API-002 整次生成任务删除

**Goal：** 为可删除状态提供不可恢复的整任务删除，并保证运行任务、路径边界和全局播放器安全。

**Architecture：** `DELETE /api/generations/{request_id}` 只按注册表元数据定位 outputs 直属任务目录。文件删除成功后才移除内存记录；前端使用确认对话框并在删除当前播放任务时清空播放器。

**实际状态：** 见 [`STATUS.md`](../STATUS.md)。

## 2. API 与状态合同

- 新增 `DELETE /api/generations/{request_id}`；成功返回 204，不存在返回 404。
- `queued`、`running` 返回 409；用户需先停止等待。`completed`、`failed`、`stopped`、`interrupted` 可删除。
- stopped/interrupted 的前端确认文案额外说明：删除后不能再使用 taskId 继续查询远程任务。
- 删除单位是整次 generation：任务目录内 JSON、所有已保留 MP3 和封面，以及注册表/作品列表记录一起消失。
- 删除失败时保留注册表记录并返回安全、可操作的错误；不得在 UI 中假装删除成功。
- 删除当前播放任务前停止并清空全局播放器。

## 3. 安全边界与非范围

允许修改 FastAPI 路由、TaskRegistry/ArtifactStore、前端 API client、generation/player store、WorksPage、样式、测试和对应 API/数据/产品文档。

路径必须由已登记 request_id 解析，规范化目标必须是 outputs 根目录的直属子目录，拒绝根目录、越界、符号链接和客户端路径。删除前重新检查后台任务状态；不得删除运行中的目录。

不实现回收站、撤销、软删除、单候选删除、批量删除、远程 Suno 删除或自动清理策略。

## 4. 实施顺序

1. 先增加 API 测试：204、404、运行中 409、各允许状态、文件失败、路径遍历/符号链接和注册表一致性。
2. 在存储层实现窄范围安全删除，在服务/注册表层编排“文件成功后移除记录”。
3. 增加前端 client/store 删除动作和作品行删除入口；实现不可恢复确认对话框及状态差异文案。
4. 接入播放器清理、列表刷新和错误提示；补 UI/E2E 测试。
5. 同步 API_SPEC、DATA_MODEL、SPEC、PRD 和 WEB_UI_DESIGN。

## 5. 验证与完成标准

运行存储、任务、API、前端 store/UI、类型检查、构建和删除浏览器 E2E；另用临时 outputs 验证不会删除根目录或相邻任务。

完成标准：所有允许状态能整任务删除；运行中稳定拒绝；确认文案与任务状态匹配；当前播放被安全清空；失败不产生幽灵删除；路径边界和不可恢复语义有测试；验证证据只写入 `STATUS.md`。

## 6. 风险与回滚

删除不可恢复且会丢失继续查询所需 taskId，必须二次确认。Windows 文件占用可能使目录删除失败，此时返回错误并保留记录。回滚只能撤销接口和 UI 入口，不能恢复已物理删除的用户作品。
