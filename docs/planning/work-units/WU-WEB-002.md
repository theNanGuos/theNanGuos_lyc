# WU-WEB-002 创作与等待页状态修正

**Goal：** 按用户确认的新基线修正创作页和等待页，不改变生成协议。

**Architecture：** 复用现有 Vue 页面、Pinia 状态和 Heroicons；统一等待步骤布局，移除无业务含义的装饰进度条，并在进入新创作时显式清理临时预览。

**实际状态：** 见 [`STATUS.md`](../STATUS.md)。

## 2. 范围

允许修改 `frontend/src/pages/CreatePage.vue`、`GeneratingPage.vue`、相关 Pinia 状态、`frontend/src/styles/main.css`、前端测试，以及用户确认后的 `design/prototypes/01-create.png`、`02-generating.png` 和对应 UI 文档。

本 WU 必须实现：

- 将“重新生成方案”换为重试/刷新语义图标，并保留可读名称；
- 创作输入初值为空，示例仅作为 placeholder；进入一次新的创作流程时清除上一轮 preview，不实现草稿恢复；
- 移除 textarea 的蓝色内框，保留克制且键盘可见的外层焦点提示；
- 本地五个 Agent 步骤和远程“等待完整歌曲”使用相同列宽、图标槽和状态槽；状态变化不得改变网格结构；
- 删除等待页预计进度下方无业务含义的装饰竖条。

## 3. 非范围与兼容性

- 不实现候选保留数量字段，其合同归 `WU-SUNO-002`；
- 不修改结果页、作品页、播放器、删除接口或 Kie 请求；
- 不增加保存草稿、跨页面恢复输入或真实供应商进度百分比；
- 不更换整体视觉语言、导航、主要 CTA 或字段分组。若实现需要这些实质变化，先暂停并请用户确认更新后的 1440×1024 原型。

## 4. 实施顺序

1. 先为输入初值、placeholder、preview 清理、图标可访问名称、步骤结构和装饰条移除补失败测试。
2. 更新创作页状态初始化和重试图标；验证浏览器返回创作页时不会重新填入示例文本。
3. 抽取或统一等待步骤行结构，使用稳定 grid；active/done/pending 仅改变视觉状态和文案。
4. 调整焦点样式并用键盘验证可见性。
5. 在实装页面 1440×1024 截图基础上更新原型；若与已确认布局发生实质偏离，先取得用户确认。

## 5. 验证与完成标准

运行前端相关单元测试、类型检查、生产构建和针对创作/等待流程的 Chromium E2E；逐页检查 1440×1024 截图。

完成标准：九项问题中的图标、两处步骤偏移、等待页装饰条、输入重置和焦点表现均满足设计合同；键盘焦点仍可辨识；其他页面和 API 行为不变；验证证据只更新到 `STATUS.md`。

## 6. 风险与回滚

路由复用可能误清正在编辑的输入，因此只在“开始新的创作会话”边界清理 preview，不在组件任意重渲染时清理。出现视觉回归时回退局部模板/CSS，不回滚用户已有未提交工作。
